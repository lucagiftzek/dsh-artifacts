# Security policy

dsh-artifacts runs inside your DeepSeek Harness server with the same permissions as DSH itself. Please report vulnerabilities privately.

## Reporting a vulnerability

Use GitHub's private reporting: the **Security** tab of this repository, then **Report a vulnerability**. If that is not possible, email luca@tzekos.eu with "security" and the repository name in the subject.

Please include the version or commit, the steps to reproduce and the impact you see. You will get an answer within a few days. Fixes ship as a patch release with a note in the CHANGELOG, and reporters are credited unless they prefer not to be.

## Supported versions

Only the latest release receives security fixes.
