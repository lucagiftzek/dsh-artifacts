# Contributing to dsh-artifacts

Thanks for helping. This is a small project maintained by one person, so short and focused changes are the easiest to review.

- **Bugs and ideas**: open an issue with the bug report or feature request template. Include your DSH version (`dsh --version`), the dsh-artifacts version and what you expected to happen.
- **Pull requests**: one change per pull request, with tests updated and passing (`npm install && npm test`). Keep secrets, private hosts and personal data out of code, tests and fixtures; use example.com and +1 555 numbers.
- **Style**: plain English in docs and messages, no em-dashes or en-dashes.
- **Security problems**: please do not open a public issue; follow [SECURITY.md](SECURITY.md).
- **AI-assisted work** is welcome (this project is built with AI coding agents under human review), as long as you have read and tested what you submit.
